# ESP32 Projects

Experiments with ESP32 (WROOM-32) microcontrollers.

## Projects

| Project | Description | Stack |
|---------|-------------|-------|
| [led](led/README.md) | Blinking the built-in LED | PlatformIO + Arduino |
| [screen](screen/README.md) | GMT130 240×240 IPS display (ST7789) over SPI | ESP-IDF |

Each project is a separate folder with its own `README.md` (wiring, build,
important notes).
