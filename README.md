# ESP32 Projects

Experiments with ESP32 (WROOM-32) microcontrollers.

## Projects

| Project | Description | Status |
|---------|-------------|--------|
| [led](led/README.md) | Blinking the built-in LED | Active (PlatformIO + Arduino) |
| [screen](screen/README.md) | GMT130 240×240 IPS display (ST7789) over SPI | Active (PlatformIO + Arduino, TFT_eSPI) |
| [screen_new](screen_new/README.md) | GMT130 240×240 IPS display (ST7789) over SPI + HTTP server (render JSON text and RGB565 images) | Active (PlatformIO + Arduino, TFT_eSPI) |

Each project is a separate folder with its own `README.md` (wiring, build,
important notes) and a demo poster under `media/`.
